# Versionamento da entrega

A versão correspondente à Segunda Entrega deve ser identificada no GitHub por uma tag ou release. Após validar o build, executar na raiz do projeto:

```bash
git add .
git commit -m "feat: conclui segunda entrega da AEP"
git tag -a entrega-2-final -m "Segunda Entrega final"
git push origin main
git push origin entrega-2-final
```

A Primeira Entrega deve permanecer identificável por uma tag, release ou commit informado pela equipe, por exemplo `entrega-1`. O README e o formulário final devem conter o link do repositório e do vídeo.
